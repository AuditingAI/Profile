# The Reference Mark

The owner's brand, designed in Claude Design. Extracted on 25 Sep 2026 from
the canvas artifact "The Reference Mark"
(claude.ai/artifact/Tg7FZJQJwnyw5RHZgCrDVk) so it lives in the repository and
not only in the canvas.

| File | Artboard |
|---|---|
| `Main.dc.html` | The mark, its three construction notes (ring, node, crossbar), and five variants |
| `Lockups.dc.html` | Mark with name and wordmark |
| `Palette.dc.html` | Orange scale from `#FDF4EF` to `#47190A`, charcoal scale, teal accent |
| `Type.dc.html` | Type pairing |
| `Banner.dc.html`, `LinkedInCover.dc.html` | Social headers |
| `Signature.dc.html` | Email signature |
| `CardFront.dc.html`, `CardBack.dc.html` | Business card |
| `canvas.json` | Canvas layout |

**Core values:** orange `#E0662E`, deep orange `#AD4317`, darkest `#7C2E10`;
charcoal `#171A1D`, night `#0E1114`; paper `#F6F3F0`.

**The construction, in the designer's words:** the ring is an open circle, the
recurring engagement, deliberately not closed, with a 42-degree break centred
upper-left. The node floats in the break: the anchor, not part of the loop.
The A's crossbar overshoots the right leg, a reference line extended past the
figure, reaching for the ring without closing on it.

**Usable vectors** are in `assets/images/`: `reference-mark.svg` (two-tone,
primary), `reference-mark-mono.svg` (single ink), `reference-mark-micro.svg`
(heavier cut for 16-24 px). The micro cut is the favicon.

These `.dc.html` files are the design reference, not a build. They need the
Claude Design runtime (`support.js`) to render and are kept here as the record
of the brand, not as something to open in a browser directly.
