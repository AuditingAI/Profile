# Sources to Monitor

Concrete feeds. Setup is manual and one-time — roughly 20 minutes total. After
that these fill the monthly digest for you.

## Google Scholar alerts

Go to https://scholar.google.com, run each query, click **Create alert** (the
envelope icon on the results page). Alerts arrive by email.

| Query | Why |
|---|---|
| `Indus groundwater governance` | Core topic |
| `Indus basin GRACE groundwater depletion` | The quantitative strand |
| `Pakistan tubewell irrigation policy` | Agricultural economics angle |
| `"Indus Waters Treaty"` | Transboundary developments |
| `Punjab Pakistan irrigation political ecology` | Governance strand |
| `groundwater downscaling InSAR subsidence` | Method transfer from other basins |

**Author alerts.** Scholar lets you follow an author's new work from their
profile page ("Follow" → "New articles by this author"). Use this for
methodological leaders whose output you want to read on publication. Follow
several across both strands — a feed of one person is not a literature review.

## Email

Notes captured from your own correspondence — conference invitations, replies
from researchers, data-access requests — go in `inbox-notes/` as dated markdown
files, added manually.

This is deliberately manual. An automated mailbox scrape mixes personal
correspondence into a repository that is intended to become public, and the
signal-to-noise on that is poor. Write the note; keep the mailbox out of git.

**Never commit** to this repo: private correspondence, unpublished manuscripts
shared in confidence, personal contact details, or anything a third party
shared with an expectation of privacy.
