# Indus Basin Water Governance — Field Tracker

A working repository for tracking research on groundwater governance, water
policy, and climate resilience in the Indus Basin, and for building original
contributions to that field.

## Why this exists

Two goals, in order:

1. **Know the field.** Maintain a live map of who is publishing what, where,
   and on which datasets — so that any contribution is grounded in current
   literature rather than assumption.
2. **Publish into it.** Produce a regular, indexed research output on a
   sustainable cadence (see `PUBLICATION-PIPELINE.md`).

## Layout

| Path | Purpose |
|---|---|
| `FIELD-MAP.md` | Researchers, institutions, journals, datasets. The landscape. |
| `SOURCES.md` | Concrete feeds to monitor — Scholar alerts, RSS, journal TOCs. |
| `PUBLICATION-PIPELINE.md` | How Google Scholar indexing actually works, and a realistic monthly cadence. |
| `digests/` | Monthly field digests. One file per month, `YYYY-MM.md`. |
| `projects/` | Scoped research projects. Each is a candidate output. |
| `inbox-notes/` | Manually captured notes from email, calls, and conferences. |

## Conventions

**Verification status.** Facts in this repo carry a status marker. Nothing gets
cited in an output until it is `verified`.

- `[verified]` — checked against a primary source, with the URL recorded.
- `[unverified]` — plausible, from a secondary source, not yet confirmed.
- `[assumption]` — our inference, explicitly not a claim about the world.

This convention exists because the fastest way to lose credibility in a small
research community is to cite something wrong about someone's work.

**Scope.** This tracker follows *the field* — topics, datasets, publications,
institutions. It is not a tracker of individuals' activity. Named researchers
appear here the way they appear in any literature review: as authors of public
work, with citations.

## Getting started

1. Read `FIELD-MAP.md` for the landscape.
2. Set up the alerts in `SOURCES.md` — this is manual, one-time, ~20 minutes.
3. Read `projects/01-groundwater-remote-sensing.md` for the first real
   contribution and its open questions.
4. Each month, copy `digests/TEMPLATE.md` to `digests/YYYY-MM.md` and fill it.
