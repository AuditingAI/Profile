# Roadmap

| Phase | What | Gate to move on | Status |
|---|---|---|---|
| 1 | Read the core sources in full; establish whether canal-command boundaries can be obtained | Boundaries obtained, or the fallback chosen | **In progress** |
| 2 | Obtain the depletion surface; reproduce one published basin-scale figure; assemble covariates | Toolchain reproduces a known result | Not started |
| 3 | Publish the assembled dataset with a DOI; time-stamp the model specification | DOI issued | Not started |
| 4 | Run the analysis; post a preprint (EarthArXiv); submit to a journal (*Water Alternatives* or *HESS*) | Preprint public | Not started |

## Fallback if Phase 1 fails

If boundaries cannot be obtained: quantify the uncertainty in published Indus groundwater
abstraction estimates, and ask how much of the policy debate rests on figures that cannot be
defended. That question is also publishable.

## Working rules

- Nothing is claimed that has not been checked against a primary source.
- Co-authorship follows contribution, and is agreed in writing.
- Data and code are released with each output.
