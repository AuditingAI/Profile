# Inbox Notes

Manually written notes from correspondence, calls, and conferences relevant to
the field. One file per item: `YYYY-MM-DD-short-slug.md`.

## What goes here

- Substance learned from a conversation: a dataset that exists, a person working
  on something, a deadline, a call for papers.
- Outcome of a data-access request.
- Conference or seminar notes.

## What does not go here

This repository is expected to become public. Do not commit:

- Verbatim private correspondence, or anything quoted without the sender's
  knowledge
- Personal contact details — emails, phone numbers, addresses
- Unpublished manuscripts or data shared in confidence
- Anything about a person that is not their own public professional work

Write down the *fact you learned*, not the message you received. "PCRWR well
data available on institutional request, 6-week turnaround" is a note. A pasted
email thread is not.

## Format

```markdown
# 2026-09-03 — Data access, PCRWR

**Context:** reply to data request
**Fact:** [what you now know]
**Source reliability:** direct / secondhand / inferred
**Action:** [what this changes]
```
