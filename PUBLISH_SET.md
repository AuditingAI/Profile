# What goes public, and what never does

**Written 29 August 2026.** The decision Yasir asked for: the research is public because that is what
he wants to be found and partnered on. Everything else stays behind.

**This matters right now** because `main` — the branch GitHub Pages serves — carries none of this
work, and the branch holding it is roughly 380 files ahead. **Publishing by merging the whole branch
would put a great deal on the internet that was never meant to be there.** The list below exists so
that does not happen by accident.

---

## ✅ Public — the research face

The page a stranger clicks into, and the material behind it.

| What | Why it is safe and why it should be out |
|---|---|
| **[`research.html`](research.html)** | The public research page. The argument, the open gaps, where it is going, and what collaboration would help. Written to be read by someone who has never met him — a screen at FIU, a link in an email to a potential collaborator |
| [`RESEARCH.md`](RESEARCH.md) | The long-form honest account. States plainly that no hypotheses were tested and no findings exist for the AI extension |
| [`dba/QUALITATIVE/`](dba/QUALITATIVE/) | **Design only.** Protocol, interview guide, sampling plan, coding scheme, trustworthiness criteria, audit trail. No participant has been approached, so there is nothing to protect yet — and the design being visible is the point |
| [`dba/RISK_QUANT/`](dba/RISK_QUANT/) | The feasibility model and calculator. Reproducible, and the contribution is that other people can run it |
| [`dba/AI_RUNBOOKS/`](dba/AI_RUNBOOKS/) | Model-agnostic research runbooks. Deliberately portable — their value is that anyone can use them |
| [`dba/KNOWLEDGE/`](dba/KNOWLEDGE/) | Theory, constructs, methods, each with its strongest objection stated |
| `dba/00_Execution/RESEARCH_STATUS_DECK.pdf` | The eight-slide visual status |
| `dba/STUDY_OVERVIEW.md` · `dba/PUBLICATION_TRACKER.md` | The model and the honest publication state |
| The model diagrams | `Anchoring_Bias_Research_Model.png` and the v2 figure |

**Why publish the gaps rather than only the wins.** A page that lists finished work is a brochure and
reads as one. A page that states what is unresolved — including that the outcome construct measures
the wrong thing — is the thing a serious collaborator responds to. It is also the only version
consistent with a programme whose subject is overconfidence.

## ⛔ Never public

Not "not yet." These do not go out.

| What | Why not |
|---|---|
| **Participant data of any kind** | Raw or cleaned response-level data, transcripts, recordings, identifiers, linking keys. IRB-25-0462 and platform terms. Anonymised extracts appear only after member-check approval and only where a write-up needs them |
| **`career/**`** | Applications, cover letters, screening answers, compensation targets, recruiter names, application history. Industry's lane and none of it belongs on a research page |
| **`career/HANDOFF.md`** | Carries live pipeline state — named employers, decline counts, a suppressed company. Internal coordination, not a publication |
| **`live.html` as it currently stands** | The register is genuinely good, but its **Career pipeline** panel names employers and salary bands. Either that panel comes out or the file stays internal. It cannot go up as-is |
| **Advisor and faculty correspondence** | `dba/00_Execution/Rey_Final_Feedback_Dissertation_Plan.md`, `dba/correspondence/`, and the drafted emails to named professors in `dba/coursework/`. A supervisor's feedback is a private communication. Publishing it would be a breach of an ordinary professional confidence and would poison the relationship that the whole degree depends on |
| **Any PID, phone number, or personal email** | Placeholders only, per the repository's standing rule |
| **A DBA completion year or a GPA** | Both unresolved with the program office. Neither is asserted anywhere until it confirms them |

## The rule, in one line

**Publish the research and the gaps. Keep the people, the pipeline, and the data.**

If a file names a person who did not choose to be named, states a number about money, or contains
something a participant said — it does not go out.
