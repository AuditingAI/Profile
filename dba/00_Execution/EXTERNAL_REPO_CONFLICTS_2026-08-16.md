# Conflicts with the "DBA Command Center" repo — 16 August 2026

A second repository (`DBA Command Center`, Cohort 8.14/8.15) was surfaced today. It contains claims
that contradict this repository and the submitted qualifying manuscript. Recording them here before
anything from either repo is merged, quoted, or submitted.

---

## 🚨 1. The "23% anchoring effect" does not exist

Both `CLAUDE.md` and `dissertation/README.md` in that repo state, as an established core finding:

> *"Auditors accept AI outputs **23% more often** when confidence scores are displayed — regardless
> of underlying evidence quality. This 23% figure is the anchor stat for the dissertation and
> threads through interview prep, course assignments, and proposal drafts wherever it's relevant."*

**No such finding exists.** The record in this repository:

| | |
|---|---|
| Valid responses obtained | **4** (of 23 raw) |
| Hypotheses tested | **0** |
| Factor structure confirmed | **none** |
| AI-extension data collected | **none** |
| Advisor-approved framing | feasibility study, not validation |

The submitted manuscript states plainly that the required analyses **could not be performed**. The AI
extension is described throughout this repo as *in development, with no findings*. There was never an
experiment manipulating displayed confidence scores, and no measured effect of any size.

**Where a number like this leads if left in place:** it is described as threading through *interview
prep, course assignments, and proposal drafts*. Fabricated data in a graded assignment is academic
misconduct. In a dissertation it ends the degree. In a job interview it is a false statement about
one's own research that any interviewer can ask a follow-up question about.

**Action: delete the 23% claim from that repo entirely.** Do not soften it to "preliminary" or
"working" — there is no underlying observation to qualify. If it originated as a hypothetical
illustration, it must be labelled as an invented example or removed.

**Worth noticing:** the fabricated statistic is a confidence-weighted number that reads as
authoritative and was accepted without a source, then propagated into downstream documents. That is
the exact mechanism this dissertation studies. It happened here, to this project.
