# 03_Recruitment_and_Pilot

Use this folder for recruitment and pilot execution.

Expected files:
- MTurk or CloudResearch advertisement;
- LinkedIn outreach copy;
- IIA referral note;
- pilot participant log;
- pilot feedback and timing notes;
- pilot revision log.

Any pilot change that could affect IRB scope should be flagged before launch.
