# Week 8 delivery script · say the poster out loud

Toastmasters-style coaching for the one-page poster. `/` = short pause (one beat). `//` = full stop,
breathe. **Bold** = stress the word. Time target: 6 to 7 minutes.

## The script, box by box

**Open (research question banner), 30 sec**
Good evening. // Every auditor on a recurring engagement / starts with **last year's** conclusion. // Now there is a second voice in the room: / an **AI tool** / that reaches a conclusion too. // My study is about the moment / that tool **agrees** with you. //
My research question is: // How do experienced auditors **experience** / and **make sense of** / **receiving** an AI-generated conclusion / that **confirms** a judgment / they had **already** formed? //

**1 · Problem, 45 sec**
Firms and regulators are writing AI policies / on one assumption: / that **human review** / is a working control. // Research has focused mostly on **how much** auditors rely on AI. // Much less is known about what it is **like** / to receive a machine's **agreement**. // That is the gap. //

**2 · Purpose, 20 sec**
So the purpose of this **phenomenological** study / is to **understand** that experience, / for experienced auditors / in organizations that use AI tools / in live work. //

**3 · Assumptions, 60 sec**
I take a **social constructivist** view. // **Ontologically**, / there are as many accounts of this moment / as auditors who lived it. // **Epistemologically**, / their own words / **are** the evidence. // **Axiologically**, / I am an **insider**: / my career is in audit and risk at Citi and JPMorgan, / so I might hear confirmation / where there is none. // That is why I keep a **confirmation hazard log**. //

**4 · Approach, 30 sec**
**Phenomenology**, / because the question is about **lived experience**. // Not grounded theory: / I am not studying a **process**. // Not a case study: / this moment crosses many firms. //

**5 · Data collection, 60 sec**
Criterion sampling. // Five or more years in audit. / Recurring engagements. / AI tools in their work. / And the one that carries the study: // they can **recall** / one **specific** occasion / when the tool agreed with them. // Recall, / not **interpretation**. // About **ten to fifteen** people, / one interview each, / and I stop on **depth**, / not on a number. //

**6 · Data analysis, 45 sec**
Creswell's five activities. // Every statement listed with equal weight, / reduced to **meaning units**, / grouped into **themes** / in the participants' own words. // Then **what** they experienced, / **how** they experienced it, / and the **essence**. // Before I write the essence, / I re-read every transcript / looking only for what **proves me wrong**. //

**7 · Ethics and validation, 45 sec**
Three lenses. // **Participants** check their own description. / An **outside reviewer** reads a few chosen transcripts, / including one that **challenges** me. / And **my** hazard log / shows what changed my decisions. // Consent, / pseudonyms, / encrypted storage, / and nobody is approached / before **IRB approval**. //

**8 · Contributions, 30 sec**
For research: / it separates **automation bias**, / a human tendency, / from **sycophancy**, / a property of the model, / at the one moment they look **identical**. // For practice: / it tests whether human review / is the control / policies **assume**. //

**9 · Limitations, 20 sec**
A small sample, / recalled experience, / and no claim to generalize. //

**Close, 15 sec**
The machine agreeing with you / **feels** like evidence. // [pause, look at the camera] // My study asks / whether it **is** experienced that way, / and what auditors **do next**. //
As noted on the slide, / I used AI to help lay out the poster; / the research decisions / are **mine**. // Thank you. // [stop talking]

## Delivery, Toastmasters style
1. **Pause instead of "um".** When you lose your place, close your mouth and breathe. Silence sounds confident; filler does not.
2. **Rule of three.** Your best lines come in threes ("Five years. Recurring engagements. AI tools.") Let each one land.
3. **Stress one word per sentence**, the bold one. Not every word.
4. **Look at the camera, not the screen**, on the research question and the closing line.
5. **End the sentence down.** Statements drop in pitch at the end. Rising at the end sounds like a question.
6. **Breathe at every `//`.** Low, from the belly, before the next sentence.
