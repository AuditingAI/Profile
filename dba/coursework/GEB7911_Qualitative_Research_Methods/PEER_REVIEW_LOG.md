## What a review of an Introduction draft should check

Reusable, from the Fall 2026 proposal rubric. Built while doing the 11 September review, so the next
one takes minutes rather than an evening.

| Rubric item | The question to ask |
|---|---|
| **Narrative hook** | Does sentence one state a controversy, a number, or a leading study? A topic statement is not a hook, and this is the cheapest band to move |
| **Research problem** | Is it argued as "why this matters," or only asserted? |
| **Literature summarized** | Groups of literature, not detail. Detail belongs in the Literature Review |
| **Gaps** | For grounded theory the rubric wants it explicit: **existing theories are inadequate for this context.** "More research is needed" is the middle band |
| **Audience** | Named audiences, and what each would do with the findings |
| **Purpose statement** | All six script blanks filled. **The site blank is the one people fudge** |
| **Research question** | What or How, open-ended, non-directional, encoded for the approach, and **carrying the context**. The rubric's own example puts the setting inside the question |
| **Framework** | Social constructivist, with all four assumptions. **Is the axiology first person?** "The researcher acknowledges" is a promise, not a positionality statement |
| **Terminology** | Defined, and not circular with the research question |

### Two traps worth checking every time

**Approach and framework compatibility.** Social constructivism plus grounded theory needs
**Charmaz**, not Glaser and Strauss. Classic grounded theory is objectivist and contradicts a
"multiple realities" ontology. Naming the variant costs one citation and closes the question.
The same trap exists for phenomenology: transcendental (Husserl, Moustakas) brackets the researcher
out, hermeneutic (van Manen) does not, and a constructivist framework points to the second.

**A prior framework that already answers the question.** If the draft cites a recent paper that
already supplies a model of the phenomenon, ask how the study avoids confirming it. Usually the
answer is in the cited paper's own limitations section, and promoting it into the gap paragraph is
what converts a soft gap into the rubric's language.
