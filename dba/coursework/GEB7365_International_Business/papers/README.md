**A grep gotcha worth remembering:** these PDFs use typographic ligatures. Searching
for `findings` fails where the file contains `ﬁndings` (U+FB01). Normalise before
searching: `.replace('ﬁ','fi').replace('ﬂ','fl')`. That is why the Arregle quote
appeared missing on a first pass when it was in fact exact.
