# Sample size table

AI-use disclosure: simulation code and tables drafted with Claude (Anthropic) on 20 Oct 2026 as an analysis aid; assumptions and interpretation to be reviewed and owned by Yasir Malik.

Generated by `power_sim.py` (seed 20261020, 2000 replications per cell, 5 items per construct, loadings U(0.70, 0.80), background paths 0.10, intervention intercorrelation 0.30). Simulation time 71 s.

Two-tailed alpha = .05. Power = share of replications in which the test rejects. Estimation = mean-score composites + OLS, an approximation of PLS-SEM. Minimum N is interpolated between grid points (30, 50, 75, 100, 150, 200, 300, 500, 750, 1000) and rounded up to 5.

## 5. Rules of thumb for comparison

Inverse square root method (Kock & Hadaya, 2018): N_min > (2.486 / |p_min|)^2, for 5% significance and 80% power. The constant 2.486 is 1.645 + 0.842, a one-tailed 5% test. The simulation above is two-tailed, which by itself requires about 26% more N.

| p_min | Inverse square root N_min | Two-tailed analogue ((1.960 + 0.842) / p_min)^2 |
|---|---|---|
| 0.10 | 619 | 785 |
| 0.20 | 155 | 197 |
| 0.30 | 69 | 88 |

Ten-times rule (10 x the largest number of arrows pointing at one construct; all constructs here are reflective):

| Model | Largest in-degree | Ten-times N |
|---|---|---|
| QUAL | 10 (RAB: 8 interventions + AJQ + APR) | 100 |
| CHAIN (illustrative) | 3 (M1: X, W, X x W) | 30 |

The ten-times rule does not depend on effect size, which is why it can sit far below the simulated N for small paths.
