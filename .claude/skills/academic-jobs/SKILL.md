# Academic jobs — the doctoral track

**Hard separation.** This track and `/job-search` never appear in the same output, never share a
resume, and never share a voice. Industry materials in an academic packet read as "consultant passing
through"; academic materials in an industry packet read as "leaving for industry." Keep them apart.

Read `career/academic/ACADEMIC_JOB_STRATEGY.md` first — it defines the target roles, the calendar,
and the credential constraints this skill scores against.

## Step 0 — load state

1. `career/academic/ACADEMIC_JOB_STRATEGY.md` — targets, calendar, sequence
2. `career/ACADEMIC_CV_YMalik.md` — check the three blocking `[CONFIRM]` items are resolved before
   recommending any application
3. `dba/PUBLICATION_TRACKER.md` — publication status changes what is realistic. Report P1's state in
   every digest; it is the binding constraint on this whole track.

## Step 1 — sweep the right sources

**Do not use Indeed or LinkedIn job alerts for this track.** Measured across multiple sweeps, they
return nursing and social-work adjunct roles in unrelated states. Academic hiring does not run
through general job boards.

| Source | How |
|---|---|
| **AAA Career Center** (aaahq.org) | Accounting-specific, primary source |
| **HigherEdJobs** | Broadest teaching-track and lecturer coverage |
| **Chronicle Vitae** | Secondary |
| **Institution portals** | FIU, Rutgers Newark, NJIT, Montclair State, Seton Hall, FDU, Baruch/CUNY, Pace, St. John's, Fordham — check directly |
| **Gmail** | Any AAA, HigherEdJobs, or institutional alerts; and **faculty correspondence, which outranks every posting** |

A reply from a professor is worth more than any listing. Escalate it to the top.

## Step 2 — score

| Score | Role type |
|---|---|
| **5** | Professor of Practice · Clinical Professor · Professor of Professional Practice — accounting, auditing, AIS, or AI governance |
| **4** | Lecturer · Senior Lecturer · Instructor, teaching-track |
| **3** | Tenure-track Assistant Professor at a teaching-intensive institution · adjunct at a target school |
| **2** | Adjunct elsewhere · non-teaching academic staff |
| **1** | Tenure-track at R1 / doctoral-granting — **not competitive this cycle** without publications; list only, never recommend |

Weight geography: NY/NJ metro, or fully online/hybrid for Miami and FIU. Note the posting date
against the calendar — teaching-track lines post later and less predictably than tenure-track ones.

## Step 3 — packet readiness

Per recommended role, name exactly which documents the posting requires and which exist:

- Academic CV — ✅ exists, **check the three `[CONFIRM]` items are resolved**
- Research statement — ✅ `career/academic/RESEARCH_STATEMENT.md`
- **Teaching statement — ⬜ does not exist yet.** Most postings require it. Flag this every run until
  it is written; it silently blocks applications.
- Cover letter — build per institution
- Writing sample — the qualifying manuscript, or P1 once submitted
- Teaching evaluations — none exist; adjuncting is what produces them
- References — Dr. Rey and Dr. Aguirre-Urreta must be **asked**, never assumed

## Guardrails

- Draft anything; **send nothing without per-item approval.**
- Never fabricate a posting, an institution, or a deadline.
- Never recommend applying while a CV `[CONFIRM]` item is unresolved — committees verify degree dates
  and a discrepancy is disqualifying in a way a missing line is not.
- Never overstate the credential. The DBA maps to Scholarly/Instructional Practitioner under AACSB,
  not automatically to Scholarly Academic. Say so when a posting requires the latter.
- Never claim publications, teaching evaluations, or memberships that do not exist.
- Keep this track's output entirely separate from `/job-search`.
